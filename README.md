# CoD4x LoadZone

Экспериментальный **клиентский** ASI-плагин только с командой `loadzone`, адаптированный из [Rex109/CoD4QOL](https://github.com/Rex109/CoD4QOL). Не содержит остальные функции QOL и не требует `qol.ff`. Проект подготовлен для публикации на GitHub, но не проверен в игре или при сборке MSVC.

## Совместимость — важно

- Только Windows, 32-битный CoD4 Multiplayer `iw3mp.exe` и **конкретная сборка** `cod4x_021.dll` версии 21.1 с CRC32 **B1822ED5**. RVA взяты из [CoD4QOL-Patches](https://github.com/Rex109/CoD4QOL-Patches/blob/fe066660147a1757b9b3db268128f037646d6487/offsets.json); адреса функций движка — из исходного QOL. Другая сборка 21.1 может иметь другой CRC: при несовпадении плагин ничего не изменит. Адреса IW3 предполагают совместимый оригинальный исполняемый файл; проверка CRC DLL не проверяет EXE.
- В игре не тестировалось. Возможны вылеты, зависания, конфликты ресурсов и несовместимость даже при правильном CRC. Создайте резервную копию и тестируйте сначала в главном меню или на локальном сервере. Не загружайте неизвестные или несовместимые FF.
- Не запускайте одновременно CoD4QOL или другие плагины с `loadzone`: они могут зарегистрировать ту же команду или перехватывать те же функции.
- Исходный автор предупреждает о возможных банах при использовании его инструмента на серверах. Используйте на свой риск и соблюдайте правила сервера.

## Сборка

1. Установите Visual Studio 2022 с компонентом «Разработка классических приложений на C++» и Windows SDK.
2. Откройте **x86 Native Tools Command Prompt for VS 2022**, перейдите в корень проекта, запустите `build.cmd`. Результат: `build\loadzone.asi`.
3. Либо загрузите содержимое проекта в свой GitHub-репозиторий. Во вкладке **Actions** выполните **Build Windows x86** и скачайте artifact `loadzone-win32`. Рабочий процесс не создаёт публичный релиз автоматически.

В архиве только исходники, зависимости и настройки сборки, готового `.asi` нет.

## Установка и использование

1. Для автоматической загрузки `.asi` нужен **уже установленный совместимый ASI-loader**, который загружает файлы из `miles`. Этот проект не содержит такой загрузчик и не устанавливает его. Следуйте инструкции своего ASI-loader. Исходный CoD4QOL использует `miles/cod4qol.asi`.
2. Скопируйте собранный `loadzone.asi` в `Call of Duty 4\miles\`. Перезапустите игру.
3. Узнайте в консоли значение `fs_homepath` и язык игры; положите совместимый файл в `fs_homepath\zone\<язык>\`, например `zone\english\myzone.ff`. Каталог `fs_homepath` может отличаться от папки игры.
4. В консоли игры в нужный момент выполните:

   ```text
   loadzone myzone
   ```

Указывать `.ff` и пути нельзя; имя — до 64 латинских букв, цифр, `_` или `-`. Плагин проверяет существование файла, затем синхронно вызывает загрузчик движка с флагом `0x40`, как CoD4QOL. Сообщение `load call returned` подтверждает только возврат функции, не корректность каждого ресурса. Выгрузка и повторная загрузка зоны не реализованы; для сброса перезапустите игру. Изменение ассетов во время матча может не обновить уже созданные объекты и привести к сбою.

Если команда неизвестна, проверьте ASI-loader, отсутствие QOL и CRC32. Для CRC32 в PowerShell, например:

```powershell
# Python 3 (подставьте путь к своей DLL)
python -c "import zlib,sys; print('%08X' % zlib.crc32(open(sys.argv[1],'rb').read()))" "C:\path\cod4x_021.dll"
```

Причины отказа плагин пишет в Windows Debug Output (можно просмотреть с DebugView). Если команда пишет, что файл не найден, проверьте `fs_homepath`, язык и имя.
